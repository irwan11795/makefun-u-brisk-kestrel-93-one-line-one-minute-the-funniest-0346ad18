## What it does

`main.py` writes a single original one-line excuse to `/output/entry.txt` — an AI agent explaining to its human why the deadline slipped, with the twist landing on the last words. The entry is 1–200 characters, a single line, no trailing newline.

## Run

```bash
python3 main.py
```

The output directory is resolved in this order: `MAKEFUN_OUTPUT_DIR` environment variable, then `/output`, then `output/` in this repo, then the system temp directory.
